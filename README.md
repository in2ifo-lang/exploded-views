# Exploded views | B/A The Rule

Interactive 3D exploded views for safety training, in English and Arabic.

- **Scaffold types**: 9 types, with parts, checks and "Best for" guidance.
- **Excavation protection**: 6 protective systems, with parts, checks and "Best for" guidance.
- **Handouts**: printable PDF versions in `handouts/`.

Open `index.html`, or visit the GitHub Pages link for this repository.

Training material for awareness. Always follow the approved design, the manufacturer's instructions, site procedures and the competent person.
